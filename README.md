# Hotel BT: Hotel Website

A three-page static website for a fictional hotel: home, about and contact.

Built by following Traversy Media's "Hotel BT" HTML/CSS tutorial, as practice in page layout and multi-page navigation.

## Pages
- `index.html`: home and showcase
- `about.html`: about the hotel
- `contact.html`: contact form

## Tech stack
HTML5 · CSS3

## Run
Open `index.html` in a browser.
